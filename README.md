# ArkaneDAW

A Linux-first, pattern-based DAW with FL Studio's workflow and UX, its own family of built-in instruments and effects,
VST/CLAP hosting and audio/MIDI recording. See [docs/SPEC.md](docs/SPEC.md).

```bash
npm install
npm run dev        # Electron app
npm run dev:web    # renderer only, in a browser at http://localhost:5180
npm test           # DSP unit tests
```
